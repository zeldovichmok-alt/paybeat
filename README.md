# PayBeat · 按秒计费工具

PayBeat 是一个按工作日、工作时间和午休时段计算实时收入的本地优先网页工具。

打开 [index.html](./index.html) 即可使用主工具。GitHub Pages 部署后，仓库根目录会直接显示这个入口。

## 当前版本

- 任意工作日首次打开时，从当天上班时间补算到当前时刻，并持续实时计时。
- 午休自动跳过；带薪摸鱼、离岗、拉屎、个人休息和自定义休息共用一个休息选择器，可随时切回正常计时。
- 带薪休息期间薪资冻结，回来后按剩余工作时段提高秒薪，保留休息前的预计日薪；不带薪休息按原秒薪恢复，不补计休息收入。
- 当天重新打开或刷新页面默认从设定的上班时间继续读取当天实时收入和已有账本；取消“从上班时间自动补算”后才会等待手动开始。修改工资规则时可选立即执行或下个工作日执行。
- 支持 CNY、USD、EUR、GBP、JPY、HKD、SGD、AUD 八种币种、加班和历史记录。
- 社保 / 公积金为可编辑估算，提供上海 2026 参数预填，默认不启用。
- 每个浏览器页面使用独立的本机 `localStorage` 命名空间，不接入账号、云同步或服务器数据库；设置和历史只留在当前设备和当前页面路径。Windows 桌面版使用稳定的本机存储键，换文件夹更新会保留有效工资状态。
- 设置弹窗提供清除本机数据入口，适合多人共用设备交接。
- V2 第一阶段：主页面金额默认遮挡，按下立即查看，松手或切页立即隐藏；设置编辑页会显示填写内容。
- 桌面页面保留轻量预览桌宠；Windows 本地版提供独立透明置顶浮窗，可在桌面拖动。小人持续向前走，路面向后延伸，不按固定周期回到起点。今日真实收入每跨过 0.5 元收小金币，每跨过 20 元收大金币，每跨过 100 元出现旗子；同一时刻优先展示最高级别奖励。休息时停住，不补播历史奖励。

Windows 桌宠默认使用 C「月白猫帽」，右键「换装」可切换 A「薄荷旅人」和 B「樱桃快跑」。底部按钮和小字已移除，工资工具、休息 / 继续、换装、安静、检查更新、隐藏及退出统一放在右键菜单，键盘 Shift+F10 也可打开。三套皮肤使用六步交叉腿动作序列，金币靠近时张嘴，收入达到门槛后从脸旁滑入口中、吞入、鼓腮，再接回当前行走相位。轻点人物招手，拖动移动；草地、小花、石子、路牌与小互动保留。外观选择仅存本机，切换不影响工资。

## 页面入口

- `index.html`：GitHub Pages 默认主工具入口。
- `pay-by-second.html`：主工具副本，逻辑与 `index.html` 保持一致。
- `pay-by-second-readymag.html`：原有 Readymag 视觉版，保持独立。

## 本地运行

Windows 桌宠：双击根目录「打开 PayBeat.exe」或桌面上的「PayBeat」快捷方式。首次填写工资后即可使用，不需要命令行。工资窗口关闭后桌宠仍继续运行；退出请右键桌宠或托盘选择「退出 PayBeat」。

给其他 Windows x64 电脑使用时，完整解压「PayBeat-桌面桌宠-Windows.zip」，再双击其中的「打开 PayBeat.exe」。启动器需要同包的「本地桌宠」文件夹，不能单独复制。每台电脑首次使用都是空白设置；个人数据只存于本机。

直接打开 `index.html` 即可使用。需要电脑和手机在同一 Wi‑Fi 下访问时，在仓库根目录运行：

```bash
node pay-server.js
```

默认端口为 `8876`，终端会打印电脑和手机可访问的地址。

## 文档和交接材料

- `PayBeat-第一轮功能优化方案.md`：本轮产品逻辑和验收方案。
- `PayBeat-V2-A+B详细方案.md`：V2 UI 与智能工作模式方案，已补充金额隐私显示和网页内像素桌宠第一阶段实现。
- `PayBeat-V2.2-小迭代方案.md`：V2.2 交叉腿动作、吞金币流畅度和版本检查方案及本地实现记录。

- `原文档/`：原始产品、架构和 UI 文档。
- `验证/`：主工具回归和边界验证脚本。
- `桌面桌宠/`：Windows 桌宠源码、构建脚本和本地使用说明；`本地桌宠/` 为本机生成的 Windows 预览，不提交到 GitHub。
- `PayBeat-按秒计费工具与原文档.zip`：按秒计费工具、原文档、预览图和验证材料的完整打包文件。
- `PayBeat-Windows-v2.1.0.zip`：GitHub Release 中的 Windows 桌宠运行包，完整解压后使用。
- `SHA256SUMS.txt`：交付文件校验值。

当前 V2.2 迭代增加三套皮肤统一交叉腿动作、吞金币收尾、工资规则生效选择和桌宠右键「检查更新」。

所有社保、公积金和到手金额均为估算，不接入地区政策、实时汇率或云端账号。

运行预览服务后，可以依次运行 `node 验证/paybeat-regression.cjs`、`node 验证/paybeat-edge-cases.cjs`、`node 验证/paybeat-settings.cjs` 和 `node 验证/paybeat-v2-interactions.cjs`。Windows 桌宠生成后运行 `node 验证/paybeat-desktop.cjs`、`node 验证/paybeat-updates.cjs` 和 `node 验证/paybeat-upgrade.cjs`。脚本使用 Playwright 与 Edge；可通过 `PAYBEAT_PLAYWRIGHT` 指定 Playwright 安装路径，通过 `PAYBEAT_TEST_URL` 指定预览地址。

V2 预览图位于 `预览图/V2/`，桌宠预览位于 `预览图/V2-桌宠/`；本轮视频为 `桌宠动作预览-V2.2-演示.webm`，验收记录位于 `验证/V2-验收记录.md`。运行 `验证/package-paybeat.ps1` 可重新生成源码文档包和文件校验清单，运行 `桌面桌宠/package-portable.ps1` 生成桌面应用包。两种包均不含个人工资、浏览器设置或历史记录；仅桌面应用包包含 Electron 运行时。GitHub 已发布版本为 V2.1.0；V2.2 仅在本地等待确认。
