# PayBeat 桌面金币伙伴 · V2.2 本地迭代版

双击项目根目录「打开 PayBeat.exe」，或桌面上的「PayBeat」快捷方式。无需输入命令。首次填写自己的工资和工作时间后，独立桌宠会跟随真实收入开始旅程。

本地 V2.2 试用包为项目根目录 `PayBeat-桌面桌宠-Windows.zip`；GitHub 上已发布的是 V2.1.0。给其他 Windows x64 电脑使用时，完整解压对应运行包，再双击「打开 PayBeat.exe」。请保留旁边的「本地桌宠」文件夹，不要只复制启动器。也可直接打开该文件夹里的「PayBeat.exe」。

- 小人所在区域和上方气泡都可以拖动。浮窗透明、置顶，可移到桌面的任意位置。
- 默认皮肤为 C「月白猫帽」，A「薄荷旅人」与 B「樱桃快跑」保留。右键小人、地面或气泡，选择「换装」直接选皮肤；仅本机记住选择，新用户默认 C。
- 人物可见高度约 56–60 px，小金币直径 28 px，大金币约 36 px。金币随到下一个 0.5 元门槛的进度靠近，到嘴边吃入并庆祝。
- 轻点小人会招手；拖动超过小幅距离才移动浮窗，不误触招手。可按 Tab 聚焦人物后用 Space / Enter 互动。
- 底部按钮和提示小字已移除。工资工具、休息 / 继续工作、换装、安静、检查更新、隐藏和退出均收进右键菜单；聚焦人物后按 Shift+F10 或菜单键也能打开。浮窗为 280 × 180 px。
- 三套皮肤都使用六步交叉腿动作序列，并加入落脚、交叉经过和重心起伏。金币即将到达时提前张大嘴；真实收入达到门槛后，金币从脸旁滑入口中并逐渐缩小吞入，再鼓腮、咽下、接回当前行走相位。下一枚金币淡入；路边互动不会抢占吃金币动作。
- 地面保留草地，加入小花、石子与路牌。经过小花会有蝴蝶，经过石子轻跳，遇到路牌会打招呼；互动不产生金币，也不影响计薪。安静或减少动画模式停止这些动作。
- 小人持续向前走，镜头跟随人物，路面不断向后延伸；不会定时回到起点。
- 今日真实收入每跨过 0.5 元，收一枚小金币；20、40、60……元收大金币；100、200、300……元出现小旗子。同一更新跨过多个门槛时，优先展示旗子，其次大金币，再次小金币，不堆积动画。其他币种按所选币种的 0.5 单位触发，不换算汇率。
- 打开应用时先接上当天的真实收入进度，历史金币不会一次性补播；之后的新收入触发奖励。电脑睡眠、重新打开或切换日期后也不补播。
- 右键「休息 · 带薪摸鱼」后，当前收入与前进都停止；「继续工作」恢复，并按原工资规则调整剩余时间的秒薪。午休和暂停时不收金币，加班时继续。没有声音。
- 右键「打开工资工具」打开计时窗口。关闭计时窗口后桌宠继续，工资计时也继续；右键桌宠或任务栏托盘可退出整个应用。
- 工资工具默认从设置的上班时间补算当天收入；只有取消“从上班时间自动补算”后，才需要手动开始。当天已有计时后修改工资规则时，会让你选择立即执行或下个工作日执行；已产生的金额和工时会保留。
- 右键「安静模式」停止人物、路面和金币动画；「隐藏桌宠」隐藏浮窗，托盘右键「召回桌宠」可恢复。
- 右键「检查更新」只读取 GitHub Release 的公开版本信息；发现新版本后，用户点击「打开下载页」才打开本项目发布页，不上传工资、历史、设备标识或本机偏好。检查失败不影响计薪，也不会后台自动更新。
- 工资主页面按下即显示金额，松手、失焦或切页即隐藏。桌宠不显示月薪、秒薪和累计金额数字；金币里程碑反映收入增量，安静模式可隐藏这类反馈。
- 本机工资、设置和历史保存在当前 Windows 用户的 `%APPDATA%/PayBeatDesktop`，不打入交付包、不上传。计薪和桌宠运行保持离线；只有用户主动选择「检查更新」时读取公开 Release 信息。窗口位置和安静偏好也只保存在本机。
- 桌面应用与普通浏览器是两个独立本地环境，首次使用桌面版需要填写一次设置，不会自动读取浏览器个人工资。不同 Windows 用户各自独立；多人共用同一账户时请在设置里清除本机数据。

当前交付为 Windows x64 桌面版，不是手机桌面挂件。电脑睡眠期间不会补播金币；唤醒后工资按真实时间校正。退出应用后无后台进程，重新打开仍按工资规则补算。

## V2.2 本地迭代

当前本地迭代版本为 2.2.0。三套皮肤统一使用交叉腿行走动作；右键菜单增加「检查更新」。检查更新只读取公开 GitHub Release 信息，不上传工资、历史、设备标识或桌宠偏好。当前版本比已发布版本更新时，会提示保留本地版本；网络失败不影响计薪和桌宠运行。换文件夹升级时，桌面版会复用当前 Windows 用户的本机数据，并迁移旧安装路径保存的有效工资状态。

## 源码与构建

使用 Electron 45.0.0 的透明无边框窗口；工资工具仍是项目根目录 `index.html`。工资工具向本机主进程发送整数收入里程碑；桌宠绘制窗口仅收到奖励种类、前进距离和工作状态，不接收工资金额、秒薪或历史记录。里程碑逻辑位于 `journey.js`。

在 PowerShell 7 运行 `./桌面桌宠/build-local.ps1`。脚本会下载官方 Windows x64 运行时并校验 SHA256，生成「本地桌宠」文件夹、双击入口和快捷方式。再运行 `./桌面桌宠/package-portable.ps1` 生成完整桌面应用包。应用包不含个人数据，该文件夹及桌面版 ZIP 不提交到 GitHub。

验证脚本：`验证/paybeat-milestones.cjs`、`验证/paybeat-desktop.cjs`、`验证/paybeat-pet-motion.cjs`、`验证/paybeat-settings.cjs`、`验证/paybeat-updates.cjs`、`验证/paybeat-upgrade.cjs`。测试工资仅写入临时测试目录，更新测试使用模拟网络响应。`预览图/V2-桌宠/桌宠动作预览-V2.2-演示.webm` 展示本轮三套皮肤动作，使用模拟进度，不含真实工资。

若已运行旧版本，请右键「退出 PayBeat」后重新双击启动器，便会加载更新。

官方实现依据：[透明窗口](https://www.electronjs.org/docs/latest/tutorial/custom-window-styles)、[BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window)。
