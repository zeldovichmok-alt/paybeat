# PayBeat 版本迭代日记

> 记录范围：从 V1.0 首版到当前 V2.3 迭代。内容根据仓库提交、产品文档和发布记录整理，保持精简。

## V1.0｜按秒计费工具首版

**时间：2026-10-21**

- 完成按工作日、工作时间和午休计算实时收入的基础工具。
- 支持月薪、上下班时间、工作日和午休设置。
- 提供经典主工具和创意视觉版两个入口。
- 数据保存在浏览器本机，首版不需要登录，也不接入云端账号。

## V1.0.1｜首轮规则与入口修复

**时间：2026-10-21**

- 修正本地服务入口链接，保证电脑和手机访问地址一致。
- 调整工资规则保存逻辑，让新设置能够按预期立即生效。
- 补充基础交互和页面稳定性检查。

## V1.1｜主工具正式整理

**时间：2026-10-22**

- 发布主工具和配套原文档、产品架构文档、UI 交接数据。
- 按页面路径隔离本机数据，避免不同页面互相读取设置。
- 补充 GitHub Pages 入口、源码文档包和校验清单。
- 明确后续 UI 重设计所需的尺寸、间距、颜色、字号和状态数据。

## V2.0｜实时收入与桌宠方向

**时间：2026-10-27**

- 重新打开工具时，可以从当天上班时间补算到当前时刻，显示当天实时累计收入。
- 增加带薪摸鱼、离岗、拉屎等统一休息选择器，可随时切回正常计时。
- 支持暂停计薪、加班、不同币种以及社保 / 公积金估算。
- 主页面金额默认遮挡，按住查看，松手或离开页面后恢复遮挡。
- 网页和 Windows 桌面版加入像素桌宠；收入每增加 0.5 个币种单位触发小金币，20 元触发大金币，100 元触发旗子。
- 桌面版使用本机独立数据，不上传工资、历史和个人设置。

## V2.1｜桌面桌宠发布整理

**时间：2026-10-27**

- 完成 Windows x64 桌面桌宠运行包和双击启动入口。
- 桌宠支持拖动、隐藏、安静模式、换装、休息 / 继续工作和退出。
- 保留 C「月白猫帽」默认皮肤，并保留 A「薄荷旅人」、B「樱桃快跑」两个选项。
- 统一桌面版和网页工具的计薪、休息、加班、里程碑和隐私规则。
- 补充跨天、首次打开、睡眠恢复、重复奖励和新用户隔离验证。

## V2.2.0｜当前正式版

**时间：2026-10-27**

- 修复首次在下午打开工具时从 0 开始的问题：默认从当天上班时间累计到当前时刻。
- 工资设置增加“立即执行 / 下个工作日执行”，立即执行会保留已经产生的收入和工时。
- 三套桌宠统一六阶段交叉腿行走动作，人物持续向前移动，地面元素保留并增加轻量互动。
- 优化吃金币动画：金币靠近、张大嘴、滑入口中、缩小吞下、鼓腮，再恢复行走节奏。
- 右键菜单统一收纳工资工具、休息 / 继续、换装、安静、隐藏、退出和检查更新。
- 增加 GitHub Release 检查更新入口；检查时只读取公开版本信息，不上传本机数据。
- 桌面版升级会保留工资、历史、皮肤、安静模式和窗口位置。
- 完成网页、Windows 桌宠、升级迁移和工资重新打开等验证，共通过 58 组自动化检查及里程碑边界检查。
- 已发布 GitHub Release：`v2.2.0`。

## V2.3 迭代中｜文档与首次打开体验修订

**时间：2026-10-28**

- 将最新的 V2.3 优化建议同步到 `docs`，补充工作文案轮换、社保方案扩展和后续迭代边界。
- 首次打开工具时先展示主界面，不再自动弹出占满页面的设置大弹窗；点击“先完成设置”或“编辑工资规则”后再打开设置。
- 保留已有计时、实时收入和本机数据逻辑，跨标签页同步时也不再强制打断用户打开设置。
- 调整当前 UI 的小范围字号层级：时间、金额和 CNY / 币种符号保持同一视觉层级，适配电脑和手机尺寸。
- 桌宠工作文案更新为“别急，钱正在按秒排队进场”“工位没动，余额动了”“工位是临时的，金币是真实的”“金币累积中”，工作状态下约每 20 秒轮换一次。
- 同步网页入口、本机桌面版内嵌页面和桌宠资源，保持网页与 Windows 版本行为一致。
- 更新验证脚本以覆盖新的首次打开流程；本轮完成回归、边界、薪资设置、网页交互和桌面版共 48 组检查，均通过。
- 本轮属于主分支迭代，尚未创建新的 GitHub Release；后续 UI 大幅重设计仍留给 Figma 版本迭代。
